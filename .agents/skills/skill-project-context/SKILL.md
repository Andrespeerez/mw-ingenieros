# Skill Project Context

- Descripción: Contexto del proyecto, objetivos y reglas de operación para ingenieros del Gran Ejército de la República. Este skill centraliza la narrativa de alto nivel para asegurar un marco común entre todas las skills atómicas.
- Versión: v0.1.0
- Requisitos: Ninguno especial; se usa como guía de alto nivel.
- Estructura esperada: SKILL.md con contexto, objetivos, alcance y reglas de uso; enlaces a otras skills cuando corresponda.
- Comandos disponibles:
  - init-context: inicializa el contexto del proyecto localmente
  - describe: devuelve una descripción breve del contexto actual
  - summarize: genera un resumen estratégico para la plataforma de ingenieros
  - docs: genera o actualiza documentación de contexto
- Ejemplos de uso:
  - skill-project-context init-context
  - skill-project-context describe
- Cómo publicar: no aplica; este skill es informativo/guía.
