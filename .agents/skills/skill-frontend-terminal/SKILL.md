# Skill Frontend Terminal Web
- Descripción: Frontend en React + Tailwind que emula una consola de terminal retro con un menú lateral de navegación y panel derecho de contenido.
- Versión: v0.1.0
- Requisitos: Node.js >= 18; React; Tailwind (config básico opcional)
- Estructura esperada: src/, public/ (si se usa Vite), components/ (Sidebar, ContentPanel, Login), pages/ (Home, Dashboard), styles/
- Comandos disponibles: init, start, scaffold-page, load-content, login
- Ejemplos de uso: iniciar app, añadir página base, cargar contenido en el panel derecho
- Notas: La UI admite modales y componentes reutilizables para futuras extensiones
